
# Formulário de Cadastro Responsivo

Um formulário de cadastro web simples, moderno e intuitivo, desenvolvido com foco em boas práticas de HTML5 e estilização em CSS.

## 🚀 Funcionalidades

- **Campos Estruturados**: Captura de dados pessoais completos (Nome, E-mail, Telefone, Data de Nascimento e Idade).
- **MÁscaras e Orientação**: Indicadores claros nos campos (placeholders com formatos pré-definidos para facilitar o preenchimento do usuário).
- **Validação Nativa**: Regras de intervalo e tipos de input definidos para garanitir a consistência das informações inseridas.
- **Design Clean & Moderno**: Interface limpa em card centralizado, com bordas suaves e foco em legibilidade.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do formulário.
- **CSS3**: Estilização, espaçamentos, tipografia e efeitos de entrada.
