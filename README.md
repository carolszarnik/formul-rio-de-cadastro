# formulario-de-cadastro
Projeto de formulário de cadastro responsivo focado em boas práticas de interface e experiência do usuário. O projeto conta com campos para dados pessoais (nome, e-mail, telefone, data de nascimento e idade), usando orientações visuais e formatações claras em cada campo para facilitar o preenchimento. Desenvolvido inteiramente com HTML5 e CSS3.
